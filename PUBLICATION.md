# Publication notes

Blackjack app (folder: HandTracker) is being preserved as a public-source candidate.

Current scope: Card/deck models, blackjack game logic, strategy hints and a substantial SwiftUI view. This is not camera hand tracking.

Preparation still required: Rename/document it clearly, add screenshots and license, clean Xcode user metadata, and build/play-test the actual app.

Some demos need replacement assets before they run. Existing validation documents describe earlier checks and have not been rerun for this export.
